# Z10：从元末转为明朝，再远征获取制度的阶段战报

整理日期：2026-10-15。入口：[视频总览](Video_Cases.md) · [玩法主文](../EU5_Gameplay_Reference.md) · [视频阅读记录](../../research/EU5_Gameplay_Video_Reading_Log.md)。

来源：[太浪有风险《大明全流程实况》](https://www.bilibili.com/video/BV1ZW1PBHEvg/)，2025-10-31，114:47。作者片头感谢提前展示机会，属于发售前内容，未核实精确构建号。标题的“全流程”不能理解为完整 500 年：视频从 1337 元朝出发，经过红巾军转为明政权，末段到 1378 年左右完成欧洲远征并启动制度分享。

**实际审阅：**完整音轨初始机器转写 232 段已逐段阅读，另读 26 个可疑时段的补转写；查看覆盖全片的 23 张五分钟抽帧及 25 张精确定位补帧，共 47 个独立时间点。并非逐秒连续观看、无误字幕或游戏内复现。补转写仍有片尾套话幻觉、同音误识别和超出截取段的时间戳；不据这些内容生成结论。

## 1. 先定义本局成功条件，再安排元末过渡（00:00—24:32）

00:00—00:56 作者提出两个目标：成立大明，以及抵达欧洲取得制度来源。开始扮演的是元朝，后经历史事件切换朱元璋政权；22:58 补帧显示元末起事事件，23:10 已切换明政权。不是在 1337 开局列表直接选择一个已完成统一的大明。

00:56—03:44 展示元朝庞大人口与大片低控制、未核心化边疆，财政与动员能力无法按地图面积直接推断。11:16—24:32 则经历黄河治理、黑死病、韩山童、红巾军和周边脱离等事件。作者主要等待切换明，不能把这段元朝衰落理解为已经尝试并验证了最优救元策略。

**可迁移的判断：**先查国家身份与局势角色是否允许预期动作，再规划转国、继承或统一目标。国家庞大而税收／征召弱可能来自控制和政治结构；瘟疫和战争还会进一步缩小人口基础。事件触发年份、角色加成与局势结束阈值只属于这局早期版本。

## 2. 选择制度是在分配未来发展的方向（24:32—47:27）

作者为明政权安排科举、改革、阶层特权、价值观、文化、内阁与法律。其选择服务两项计划：用人口与征召优势完成统一，再为取得制度和科技准备条件。

| 时间 | 操作与理由 | 能保留的知识及限制 |
|---|---|---|
| 25:32—28:27 | 比较集权与分权：作者偏好阶层／属国忠诚，认为本局道路已削减接近度成本 | 说明忠诚、税收和行政半径之间有取舍；其道路减法与“越后期集权越没用”只是简化估值，不能作引擎公式 |
| 28:56—30:20 | 为未来印刷相关制度推动创新，并查看制度起源条件；作者明确使用动态而非固定历史起源规则 | 研究路线受游戏规则影响，不能把某制度必定出现在固定城市作为本局前提 |
| 30:50—39:42 | 限制强贵族，选择有用的市民、道路与发展相关特权 | 阶层投资与国家建设互补，但给特权影响王权、其他阶层及未来撤销成本；作者“必须全给”不推广 |
| 39:42—41:17 | 根据本国大量农民选择民兵类特权，观察征召规模增加 | 政策价值依人口结构；视频中的征召数和朱元璋专属加成不能复制给普通国家 |
| 41:47—43:17 | 接纳文化容量不足时，比较主文化和人口，改为吴文化以降低其他接纳负担 | 是该旧版国家的文化容量路线，不是“任何国家主文化人口越多就无条件更好” |
| 43:21—44:27 | 内阁用于稳定与推动创新，结合君主和成员能力 | 人物能力要与任务匹配，并计算政治与时间成本；43:25 画面为任务选择，不据转写重复词编数值 |
| 45:28—46:58 | 红巾军专属行动用于控制地区和称霸，支付／恢复宗教相关资源 | 局势行动能改变征服与治理节奏，但不是所有国家都拥有的通用按钮 |

作者对多项加成称“没用”“蚊子腿”，往往只评价这个强人物、强征召、以统一和科研为目标的局面。尤其不能照搬“辅助部队不重要”“贵族一定不值得支持”“所有城市都升级”等结论。

## 3. 大量兵力仍须解决省会、要塞和补给（47:27—58:38）

47:27—50:29 因元朝版图大，作者重点处理占领效率：查省会，集中占领关键地点，配合军队围城自动化，把机动兵力留作阻击。影片演示 Shift／Ctrl 调整目标范围，但具体快捷键、自动占领条件及控制区规则应按当前界面确认，不宜从该旧片生成无条件地毯围城脚本。

51:01—52:24 明确提醒军队不能脱离补给一口气深入，要逐步推进；还观察长途移动后的士气恢复。战争目标之外，路线中能否找到食物，是选择下一处占领地的理由。

53:26—58:38 利用局势提供的战争目标与优惠条款，直接取得大片土地，部分地区暂作附属取得贡赋和赔款。**结果不是国库随领土立即上涨**：新地要整合、接纳文化，控制仍不足；取得附属虽然给钱，也增加关系维护和后续处理负担。影片中先附属、后取消关系借局势再吞并的做法是旧版交互，不推荐为现行通用路线。

## 4. 战后财政与一次败战暴露真实限制（58:38—76:43）

58:38—01:00:36 作者发现新征服地区需要购买粮食、县衙等治理建筑要维护，考虑拆减高成本设施，并借钱完成重点地区整合。画面与解说共同说明：**治理建筑提高控制的收益，必须与运行费用比较**；不能把“加最大控制”当无条件盈利。

01:01:03—01:03:04 举行议会，以议程、事件与阶层让步提高支持，比较保留议案收益和利用支持改法。改法直接付稳定的成本高，议会成为政策转向的工具。支持度阈值、额外征税持续时间和法律成本是当时版本说明。

01:06:15—01:08:39 在山东进攻时出现不利战损，01:06:45 画面可见战斗和地形惩罚；作者退却并改由朱元璋领军，还等待将领到任。重新交战后报告获胜。此例支持的是“地形、将领与部署时机能抵消纸面兵力优势”，不是证明换某个人必胜，也不能把先后战斗的全部差异归因于一个属性。

01:12:38—01:14:38 全国动员后，作者主动取消江南征召，把高控制的经济核心留给生产，改让北方兵北伐、南方兵处理南方。01:12:55 与 01:14:15 的补帧分别展示征召人口和冬季食物影响。随后冬季叠加征召减产，粮食购买拖累财政，作者担心破产。

**对任务设计的价值：**战争能力不能只按最大可动员数验收。维持核心生产、有限动员、路线分工和冬季储备都是有意义的玩家选择；要求长期全国征召可能惩罚正常经营。

## 5. 成立帝国与整合之后，转向可负担的经营（01:16:43—01:45:53）

01:16:43—01:18:46 完成主要统一战争并成立中华帝国／大明；01:17:10 为成立决议界面，01:18:10 已展示大明和更广核心。作者随后讨论新的法律、独特进步及天朝组织。核心与接纳文化的变化属于该形成国家／局势效果，不能推广成所有国家升帝国都会自动全境造核。

| 时间 | 经营选择 | 因果与风险 |
|---|---|---|
| 01:23:11—01:25:35 | 比较统一前后人口和天朝收入／对外支付 | 作者报告战争和瘟疫损失大量人口；前后疆界与人口归属也改变，不能据总量差精确计算死亡。朝贡收入不等于天朝净收益，还要看对应支出 |
| 01:25:35—01:27:36 | 在江南高控制核心发展市民产业、原料与连接，而非立即迁都大都 | 首都选址要看周围高价值人口、交通与未来方向；漆器售价和道路／河流传播数字是旧存档，不当恒定收益 |
| 01:27:36—01:28:35；01:40:56—01:42:23 | 对比台湾跨海殖民和东北陆地殖民，发现海上存在／舰队建设限制台湾进度 | 探索与殖民许可不代表能快速迁入人口；跨海与陆上路线的约束不同 |
| 01:29:05—01:31:27 | 扩贸易集市，观察贸易容量使用和国家收入增长；区分线路利润与王室分成 | 视频确有预算与线路算例，但同时有产业、时间与政策变化，不能把全部收入变化当成单变量实验 |
| 01:31:27—01:38:54 | 配合特定进步、法律、语言和阶层安排，继续提高收入与科研条件 | 对法律逐条评价是作者偏好，旧贸易效率和文化／礼仪语言用词须按当前定义拆分 |
| 01:39:21—01:41:24 | 将低收入北方区域交属国，但保留向西接壤通道，先收复辽东 | 地点的价值不只是税收，还可能是未来外交距离、出兵路线与借口前置 |
| 01:43:52—01:45:24 | 演示使命目标，说明本局开了每个节点额外奖励的设置 | 任务奖励受游戏设置影响，不能当默认所有玩家都会获得同一奖励；对 Towards Victory 的任务强度比较尤其重要 |

影片把宫廷语言与科研、人口阶层转变和同化等概念有时混讲。后续 AI 应使用主资料中的严格区分，不照抄口语。

## 6. 为制度远征欧洲：成功结果与巨大代价（01:45:53—01:54:46）

作者观察制度起源，决定从金帐方向向欧洲推进。此前保留边境地点是为了接壤和出兵；战争之后还要取得进一步的外交接触、军通和后续战争条件。军通不等于食物获取权，也不等于随时可以对沿途任意国家宣战。

01:46:20—01:48:20 调动大军从中国前往草原，出现长途行军士气耗尽、军队抵达滞后和严重非战斗伤亡。01:47:00 补帧展示长途移动后的军队，01:48:05 展示后方分工；作者承认没有照顾前方补给，主力到伏尔加时已经减员很多。这是**失败成本真实可见的远征案例**，不能只摘最后“抵达意大利”作为轻松可复用路线。

01:48:20—01:52:50 的部分初始 ASR 质量较差，经补转写可辨主要为和谈、重新动员、外交范围、请求军通和改善信任；由于补转写也有幻觉，最终不列未经画面逐项核对的全部价格和期限。可明确保留：前后两次行军耗时、外交准入与战争动员规则均约束跨洲路线。

01:52:50—01:54:22 抵达意大利后取得附属，查看制度传播，再请求分享知识。01:53:30 画面可见制度传播提示，结尾已到 1378 年左右。作者称主动分享使月传播从约 0.31 增到约 1.09，估计约七年能获得三项制度。

**结局需要准确描述：**视频完成了“取得意大利附属、启动制度传播与知识分享”这个阶段；没有再展示七年后接纳三项制度，更没有展示完整 500 年。作者说目标完成，是对其视频目标的评价；AI 不得改成“已实测 1378 年全部接纳三制度”。

## 7. 本项目可吸收的设计原则

1. 目标链可由统一、治理、财政恢复、海陆投送与知识获取组成，过程中允许玩家换重点，而非连续要求吞地。
2. 对征服与科学复合目标，验收“已建立知识渠道”“制度已传播”“国家已接纳”“进步已研究”是四个不同阶段。
3. 经济任务应允许玩家保留核心劳动力，别用无意义的全境动员指标与生产目标互相冲突。
4. 奖励治理设施时要考虑投入品与维护；奖励贸易能力时要考虑真实容量使用和国库分成。
5. 特殊局势效果、早期开发数值、玩家游戏设置和疑似漏洞，都要与原版常态区分。
