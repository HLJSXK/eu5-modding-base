# Shared EU5 knowledge

This folder contains rules and evidence intended to apply across mod workspaces. Each project retains its own overview, implementation notes, and workspace-specific anti-patterns. The complete original knowledge-entry source and destination map is `MIGRATION_COVERAGE.yaml`; the two source corpora's full source documents remain in `migration/`.

`anti_patterns.yaml` and `valid_enums.yaml` are authoritative. The files with
the `_shared` suffix are small compatibility views retained for older tooling;
they are not a replacement for the complete registries.
