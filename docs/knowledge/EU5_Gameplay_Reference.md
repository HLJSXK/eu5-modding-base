## 1. 一局 EU5 的基本循环

EU5 从 1337 年的国家、人口和政治关系出发。国家能取得土地，但土地的产出、人口、治理和国际环境决定它能否真正转化为国力。玩家通常同时管理以下循环：

1. **治理**：任命内阁、处理阶层与法律，使国家有能力管理已有土地。
2. **生产**：人口就业于 RGO 和建筑，消耗投入商品，产出商品与利润。
3. **变现**：地方财富经控制力形成可征税税基，再由阶层财富份额和税制进入国库；贸易、粮食及其他收支同时影响财政。
4. **投资**：把国库、商品和时间投向道路、港口、产业、教育、行政或军队，处理最紧迫的瓶颈。
5. **扩张与竞争**：通过战争、外交、联统、属国、市场和殖民扩大影响，带来新的成本与整合负担。
6. **恢复与升级**：让战争人口损失、荒废和财政压力消退，传播制度、研究进步，再开启下一轮。

这些循环彼此依赖。例：新增城市工业岗位 → 需要人口转职和原料 → 需要市场供给与交通 → 投入不足会导致低效率 → 没有利润就没有预期税基 → 低控制又进一步削弱国家取得收入的能力。单纯“多造建筑”不能解释经济增长。（原版；Recap 1—3、6—7）

一局也不必以最大领土为唯一目标。Z01 围绕胡斯成就组织一百年左右的外交与宗教选择；E13 的作者把大规模修路、提高控制和整合联统视为长期经营内容，同时抱怨后期缺少差异化目标。对 Towards Victory 而言，胜利目标应给这些自然活动提供方向和阶段反馈，而不是要求玩家不断跳出正常经营去完成无关清单。（玩家经验：Z01、E13）

## 2. 不要混淆的概念

| 概念 | 玩家应理解什么 | 常见错误 |
|---|---|---|
| Location／地点 | 地图基本单元，有人口、资源、建筑、等级、控制、市场归属 | 把一个地点与整省混为一谈 |
| Province／省份 | 多个地点的集合；部分内阁行动以省为目标；粮食有省级池 | 把作用于省的行动误写为只作用一个城市 |
| 人口／Pop | 有类型、文化、宗教、识字率、需求和工作的人群 | 把人口数当可随意花费、马上恢复的点数 |
| 地方财富／Wealth | 原料、建筑和部分市民贸易带来的利润 | 把商品销售总额或地方财富全算作国库收入 |
| 税基／Tax Base | 地方财富乘以控制力形成的可征税部分 | 把税基等同税收；税收还受阶层份额和税制影响 |
| 控制力／Control | 国家从地点获取税基、征召与人力等能力 | 把它当产量、市场可及性或文化接受度 |
| 接近度／Proximity | 沿地形与基础设施从首都传播的行政联系，影响控制上限 | 只计算直线距离，或认为修路立即把控制设满 |
| 市场可及性／Market Access | 地点到其市场中心的经济联系，影响商品获取等 | 认为国家首都、市场中心一定是同一地点 |
| 市场吸引力／Market Attraction | 影响地点归属哪个市场 | 当成自己在市场中优先买货的顺序 |
| 贸易优势／Trade Advantage | 在市场竞争有限出口货源的优先程度 | 与贸易容量、贸易距离混用 |
| 贸易容量／Trade Capacity | 在某市场可用于贸易的运力预算 | 当作自动增加的国家税收 |
| 整合／Integration | 将征服地点纳入国家行政体系的过程 | 直接等同造核心或吞并属国 |
| 核心／Core | 已整合地点满足主要／已接受文化多数等条件后的状态 | 直接照搬 EU4 花行政点造核 |
| 联统／共主邦联 Union | 共主国家通过国际组织及其法律组织统治和合作 | 当成普通 `vassal` 附庸类型或君主死后自动全吞 |
| 外交官／Diplomats | 外交行动可消耗或按月占用的活动资源 | 直接套用 EU4 的固定几个外交官人物 |
| 阶层满意度／Estate Satisfaction | 阶层对统治的态度 | 与单个 Pop 满意度、国家稳定度互相替代 |
| 时代／Age、制度／Institution、进步／Advance | 时代开放知识范围，制度传播与接纳解锁许多进步，研究取得具体效果 | 把时代到来写成全国自动获得全部科技 |

以上以原版百科为主，相关 key 和定义定位见[本地原版证据](gameplay/Vanilla_Evidence.md)。原版有效地点等级还包括 `megalopolis`；E14 所说“只有乡村、城镇、城市三档”不足以描述当前工作区。

## 3. 开局与阶段性操作

### 3.1 第一次取消暂停之前

以下是综合检查顺序，不是所有国家都应做的一套机械操作。

1. **先确定生存条件与近期目标。** 是否身处战争、联统、附庸或灾难？邻国谁能威胁自己？目标是摆脱宗主、取得某地区、选帝、贸易起家，还是准备殖民？先看对应局势和国家特殊行动。
2. **盘点现金流与动员成本。** 分开看和平收支、战时征召后收支、现有债务、铸币与通胀、要塞和舰队维护。先保留应急资金，再安排建设。
3. **查看核心区与边缘区。** 在人口、控制、接近度、市场、市场可及性和粮食地图间切换。找出“富但拿不到税”“人口多却缺岗位”“工厂缺投入”“城镇缺粮”的地点。
4. **安排人物与国内政治。** 查看君主、继承、内阁空位、可执行内阁行动、阶层满意度与特权、议会。当前本地政治影响力说明明确：空内阁席位按零能力计入平均，长期空置会损失积累。
5. **安排外交安全。** 查看盟友是否愿意参战、关系容量、通行、潜在包围网、宗主或皇帝干预。先有保障，再投入会削弱短期军力的长期建设。
6. **检查研究与制度。** 当前可研究什么、缺哪项制度、是否需要内阁学习制度；优先解决近期计划的前置条件。
7. **只做能说明因果的第一批投资。** 例如补建材投入、利用现有劳动力扩 RGO、连接高财富低控制区域、增加实际有需求市场的贸易容量。不要因为某攻略说“全造”而全国铺开。
8. **设置自动化边界。** 让自动化执行已确定的政策；关键商品进口、战略建设和战争应保留人工审查。取消暂停后核对实际结果。

参考：E01—E08、E11，Z02、Z04—Z06、Z08；具体迁都、拆堡、分封方案见案例，不视为通用开局动作。

### 3.2 每次月结、和平与开战前分别看什么

| 时机 | 优先查看 | 发现问题后的行动 |
|---|---|---|
| 政策或建设后月结 | 现金流、实际就业、建筑效率、投入短缺、关键商品价格 | 区分临时调整与结构性缺口，避免连续加码错误投资 |
| 准备开战 | 可动员兵力、将领、粮食、补给路径、军事通行、盟友承诺、战争目标 | 先解决能否走到与能否围下目标，再评估决战 |
| 战争拖长 | 征召造成的经济损失、战损人口、战争疲劳、敌援、债务 | 缩小目标或停战，勿以已花成本为由无限追加 |
| 刚获胜 | 剩余军力、荒废、国库、整合任务、文化宗教、敌对感 | 把恢复和治理排入时间表，防止马上再战超出能力 |
| 市场易主或边界变化 | 地点市场归属、可及性、外贸路线、税收、原料价格 | 重新计算整个经济计划，原盈利路线可能失效 |
| 新时代／接纳制度 | 新进步、新产业、新兵种、新外交与殖民能力 | 围绕战略解锁选择研究，复核旧军队与产业布局 |
| 大规模人口损失后 | 就业空缺、粮食需求、可征召人数、建设回收时间 | 先用剩余人口维持关键产业，暂停依赖满员的新工程 |

### 3.3 局势与灾难会改变“本局现在该做什么”

黑死病、百年战争、红巾军、胡斯战争和意大利战争等，不是换了名字的普通征服战。玩家可能有专属角色、进度、行动、参战规则或结束条件；通用宣战和割地不能代替对局势目标的理解。（Recap 1、7；TT106）

遇到局势先看：自己处于什么阵营／身份、谁能发起行动、进度怎样增长、哪些操作可结束或升级冲突、失败代价是什么。国家灾难则应逐项查触发与结束条件，再决定付政治成本预防、缩小领土负担，还是接受一次损失。Z04 只能说明这种拆解方法，不能复用其旧灾难判定 bug。

瘟疫中，贸易收入与传播风险可能发生冲突；战后或疫后建设也要按剩余劳动力重新估算。Z01 的严重人口损失说明防疫投资不是“保证零损失”的按钮，玩家需要的是减损、储备与恢复计划。（Recap 1；Z01）

## 4. 经济：从人口和商品到国家收入

### 4.1 钱从哪里来

原版百科给出的重要关系是：

> 地方财富 = RGO 和建筑销售商品的利润，部分地点还包括市民贸易贡献；可征税税基 = 地方财富 × 控制力。阶层按当地财富份额分配财富，国家再按税制征收。

这里可以直观理解，不能随意补成未经核对的完整引擎公式。例如“100 财富、50% 控制”意味着税基层面约为 50，**不代表国库每月收到 50**。本地 `tax_rate` 是对 `max_tax` 的比例，税收滑块显示 100% 也不是拿走全部社会财富。（原版：`game_concept_wealth_desc`、`tax_base_desc`、`tax_rate_desc`）

因此有四类不同的经济动作：提高真实利润、提高国家控制、调整阶层财富／税收安排、增加其他合法收入。它们可以互补，也有相互伤害的可能：把税拉高可能让阶层不满，补贴工业可能短期亏钱，开放出口可能提高原料利润却伤害下游制造。

铸币能换取短期资金，但须查看通胀及其长期成本。E14 关于“金银必须同时有”“完全不铸币也必因矿山通胀”等绝对表述未经本轮验证，不作为通用规则；以当前铸币和通胀提示为准。不要把高铸币下的账面盈余当成经营已可持续。（原版；E14 为需复核旧经验）

### 4.2 RGO：资源在地上，还需要人去生产

一个地点通常有一种主要原材料资源。RGO 有已建等级与最大规模；本地百科写每级最多雇用 1,000 个适格 RGO Pop，当前用工为劳工与奴隶。农民可以通过人口流动转成适当劳动类型，但不应把“当地有一万人”当成“一万人已经可立即上岗”。（原版；Recap 1、3）

投资 RGO 前看五件事：

- 资源的现价、需求及可能的出口／下游用途。
- 当地合适劳动力、转职速度和其他产业抢人情况。
- 现有等级是否已经满员；若未满员，继续扩建未必增加产出。
- 最大规模与地理、发展、进步等限制。
- 国家能从这片地方取得多少收入，以及扩产会怎样改变价格。

人口、发展、生产潜力、满员就业和实际产出是不同层。原料扩产还会降低原料价格，可能压缩矿业利润却提高下游行业利润；对国家而言，不能只比较单个矿山施工前的收益预估。

### 4.3 生产建筑：完整检查投入、就业和销路

建工业不是简单买一个永久税收修正。应逐项解释：

| 检查项 | 要回答的问题 |
|---|---|
| 建造投入 | 钱和建材能否取得？同期大建设会否推高价格或造成短缺？ |
| 工作人口 | 需要哪类 Pop？当地已有失业适格人口，还是要等晋升／迁移？ |
| 日常投入 | 每种投入是否充足？国内有货与本地点真正拿到货是两回事 |
| 生产方式 | 当前方式适合当地原料供给吗？换方式是否引入新的稀缺投入？ |
| 产出需求 | 本市场谁买？过度扩产后价格是否仍能支持利润？ |
| 运营状态 | 实际就业、投入满足与效率分别怎样？建筑已建成不代表满产 |
| 成熟过程／Establishment | 新厂是否仍在起步？吞吐量是否尚未达到正常阈值？停业是否会损失成熟度？ |
| 国家收益 | 利润是否转成可征税税基？补贴和维护是否吞掉新增收入？ |

诊断顺序建议：**先查投入是否真正到货，再查用工，再看产出销路和价格，最后看控制与税收转换**。不要把“提升建筑效率”当成已经解决原材料可及性；项目技术知识也明确区分这两类问题。

当前百科还有 **Establishment**：新建筑起初尚未成熟，阈值以下吞吐量较低，同时少消耗投入、少产出；越过阈值后正常运行，再随成熟程度取得生产效率奖励。它按月增加，关闭建筑会损失。因此不能用建成当天的产出判断长期价值，也不能无视停业再开业的代价；具体阈值和奖励以当前定义为准。（原版 `game_concept_establishment_desc`）

战略工业可接受一段亏损，例如为战争维持武器供给；这要单列补贴预算和持续时间。补贴不会凭空创造缺失的原料。E14 将微量投入缺失说成整厂完全无用过于绝对，官方 Recap 3 反而举医院因缺汞只运行 83.33% 的例子；具体建筑的效果由当前生产与效率机制决定。

### 4.4 粮食、城市化与人口不能各自优化

省份粮食池、季节、人口消费、市场购粮和驻军供给需要一起看。城市聚集高密度人口与岗位，但增加供粮压力；农村资源区不仅是等待升级的低级城市，它可能承担粮食、原料和人口增长功能。（原版；Recap 1、3、6）

城市化前应问：能否供粮？有必要的城市建筑或产业解锁吗？当地劳动力是否匹配？升级会怎样影响 RGO 潜力和阶层结构？当前定义中乡村有 RGO 上限 +100% 加成，城镇和城市均无额外该修正，大都市为 -50%。因此乡村升城镇和城市升大都市存在直接机会成本；不能暗示城镇升城市一定继续削减 RGO。不要把“所有地点升级城市”作为繁荣通用目标。

高发展扩大土地可利用程度，正繁荣随时间促进发展并吸引迁移。低满意度、疾病、围城、占领、封锁与掠夺会损害繁荣。战争的机会成本包含失去未来增长，不能只用和平条约中的现金衡量。（原版 `prosperity_desc`、`development_desc`）

### 4.5 经济瓶颈诊断表

| 现象 | 优先区分的原因 | 可尝试的玩家动作 |
|---|---|---|
| 新厂建成却收入没涨 | 缺工、缺投入、产出降价、控制低、补贴高 | 读实际运营数据，解决具体约束后再扩建 |
| 地方富而国家穷 | 财富未转成税基、税权弱、维护支出高 | 查控制与税基、阶层税上限，再查支出 |
| 建材贵且工程很慢 | 建材缺口、贸易容量／优先权不足、同时开工过多 | 补进口或生产，分批施工，复核当前版本建设规则 |
| 大国占很多地却税很少 | 边缘地区低接近、未整合、缺行政网络 | 修治理干线，整合，评估属国管理 |
| 小国明明安全却扩建收益差 | 本市场太小、劳动力薄、没有可卖高价的产品 | 检查可参与的外国市场与贸易建筑，降低投资规模 |
| 粮食突然亏空 | 战争、季节、人口／驻军增加、产区毁坏 | 查省级池和补给需求，增加粮源和储备，调整战线 |
| 战后经济长期低迷 | 人口死亡、就业结构改变、荒废、市场重划 | 恢复和重配工作，避免照战前规划继续大建 |

## 5. 治理空间：控制、道路、港口与整合

### 5.1 三张地图必须分开看

**控制图**告诉你国家在当地能取得多少治理收益；**接近度图**解释从首都到这里的行政连接成本；**市场图与可及性**解释当地接入哪个商品体系及接入程度。修一条道路可能同时改善两种连接，但首都与市场中心不同时，两条最优线路并不一致。（原版）

当前控制会逐渐向最大控制靠拢。若最大控制不变，临时增加当前控制不一定可持续；提高上限后也未必立即满控制。上限主要关联接近度，并受整合状态、人口满意度等影响。驻军和省级内阁提高控制行动提供额外手段，但会占军力或内阁时间。（原版）

### 5.2 道路应连出有价值的网络

不要只按“哪里最暗就修哪里”选项目。比较：该路线连接多少人口、财富、关键产业和军队通道；修成后接近度／可及性提升多少；是否穿越高成本地形；是否必须经过别国土地或危险海域。

合理的阶段投资可以是：先接通核心税区 → 再接资源区和港口 → 再治理新征服边疆。对 E07 奥地利那样的山地国家，路线地形、首都和市场位置尤其重要；对海洋国家，港口容量和海上存在可能比内陆长路更有价值。此为比较框架，具体迁都不应照抄攻略。

### 5.3 海军也是和平治理设施

港口容量与海上存在能改善跨海接近联系，海军还参与贸易竞争、海上安全与远征补给。保留舰队可能有和平收益，但舰船、维护和水手都要成本。不能把“和平期间无陆战”推成“海军全拆最省钱”。（原版；Recap 6；Z02）

### 5.4 征服之后要安排治理队列

原版区分征服状态、整合与核心。整合内阁行动按省执行，速度受地点数、文化、地点等级等因素影响；已整合地点在主要文化或已接受文化占多数等条件满足时成为核心。整合行政状态、人口同化和宗教转化是不同过程，不能用同一个进度条代替。（原版）

直接持有、属国管理与稍后吞并各有代价。低接近度地区让地方附庸管理可能短期更有效，但会花关系容量，并产生忠诚、继承和整合问题；自己直接拿地则要承担行政与叛乱负担。附庸不能视为免成本的万能仓库。（E02、E06、E08；Z16 为较弱旧版来源）

## 6. 市场与贸易：利润、供给和战略安全

### 6.1 市场不是 EU4 固定贸易节点

地点属于动态市场，市场围绕中心组织，国界不必等于市场边界。市场中心易主、市场吸引力竞争、外交安排及战争可能改变既有供给结构。拥有市场中心也不代表在里面永远拥有最高贸易优势。（原版；Recap 3；Z02）

市场规模也不是越大越好：扩大范围可能增加资源种类和需求，也可能让边缘地点可及性变差。建立本国市场可改善中心附近的接入和主导权，却可能切断原来低成本的原料、奢侈品及销路。建／迁／拆市场之前应模拟完整供需，而不是只比较市场名字是否属于自己。

### 6.2 一条贸易为什么能做、为什么赚、为什么断

依次检查：路线距离及超出贸易范围的额外运输成本 → 本国在有关市场有多少容量 → 出口市场实际有多少货 → 自己有无优先取得货源的优势 → 进口后价差、关税和运输成本是否划算 → 海路、外交与战争是否稳定。当前百科明确允许超出贸易范围进行贸易，但增加运输成本，范围不是一律禁止交易的硬门槛。（原版 `game_concept_trade_range_desc`；Recap 3 的旧描述须让位于本地规则；TT124 为新版补充）

贸易可承担三种不同目的：

- **利润贸易**：利用市场价差获得收入，须防价差被自己和竞争者抹平。
- **生产保障**：进口缺少的原料或建材，使国内工业和工程能继续运转；单条路线可能亏钱，但全产业链受益。
- **政治与长期布局**：为殖民、海外据点、关键市场准入或制度联系作准备；短期收益不能单独衡量。

**贸易收入也不全部进国库。** 当前百科说明贸易收入按王权和阶层权力分配，只有王权份额进入国家财政。因此贸易面板盈利、社会贸易收入和国库实际现金增加要分别观察，买货与商人维护支出也须单独核对。（原版 `game_concept_trade_income_desc`、`game_concept_trade_desc`、`game_concept_trade_expense_desc`，定位见本地证据）

自动贸易倾向追求系统设定目标，不会自动理解作者为某次战争保留的战略库存。关键进口应确认优先权与容量；不要只看总贸易利润为正就判定供给已安全。（综合建议；E11、E14）

视频补例：Z09 64:06—67:26 建立君士坦丁堡→卡法棉花出口后，画面线路利润由约 2.52 变为 2.19；推荐利润、执行后的利润和国库收入都不能互换。51:15 的丝绸面板又区分当前价 0.66、目标价 1.00 与每月变化，说明供需改变后价格尚有调整过程。这些是早期存档观察，不是当前固定收益。（[视频入门案例](gameplay/Video_Beginner_Tutorial.md)）

### 6.3 小国为什么可以贸易起家

小国可把有限人口和资本集中在贸易容量、市场据点和高价值路线，借大市场供需扩大收入，不必先征服大量土地。Z02 的欧洲小国案例同时给出成功机制和失败条件：在外国市场经营可以成长，热那亚市场遭征服后原贸易安排与收入也会崩落。

设计贸易任务时，应看玩家是否建立可持续的参与能力：多市场可达性、战略商品供给、关键航线安全及风险分散。若只奖励某月的贸易收入，临时套利与外部市场重划都可能让任务表现偏离预期。

### 6.4 1.4 的关税与产业政策需按新界面重新判断

TT124 描述了贸易指令、按商品的进出口安排、关税和补贴组合。核心取舍是：保护本国加工行业可能需要限制原料外流、压低投入成本；鼓励原料出口则可能提高上游利润而伤害下游。关税不是无代价增加收入的滑块，实际税收还取决于是否仍有人交易。（官方预览）

完整选项、政策示例和版本边界见[官方更新](gameplay/Official_Updates.md)。禁止把 2025 年攻略的市场优势或贸易路线按钮、1.2 的贸易指令和 1.4 的新关税政策拼成一套已验证的操作。

## 7. 国内政治：阶层、人物、议会与影响力

### 7.1 阶层是经济和政治参与者

贵族、教士、市民、平民等阶层分享财富，拥有权力、满意度与特权，可能自行建设、贸易或影响军事。阶层权力高不等于满意度高；给特权提高态度也可能削弱王室税权、改变国家贸易能力或未来改革空间。（原版；Recap 2—3）

调整阶层政策时要同时看四个结果：当期财政、该阶层提供的功能、长期权力结构、撤回政策的成本。例如把贸易更多交给市民可能改善民间供给，但不必然增强国家可直接调配的贸易容量；提高税负也可能抵消教士／市民高满意度带来的研究／商业收益。具体特权以本地描述为准。

### 7.2 内阁在多个系统间分配稀缺时间

内阁既能整合和提高控制，也能处理制度等任务。任一席位投向一个方向，意味着另一项事务被延后。设计“快速整合、快速转换、快速扩张”组合目标时，要把内阁容量算进成本，不能只检查目标地点合法。

人物也不是单纯静态修正。能力、年龄、继承、忠诚／立场、担任工作和收入支出共同决定价值。给一个优秀人物安排新职位可能与内阁、将领或其他用途竞争。Towards Victory 的朝廷职位设计应说明这一机会成本，避免把“有名人”直接等同免费全国增益。

### 7.3 政治影响力的新版含义

当前本地百科：政治影响力随月积累，来自君主能力与内阁能力；内阁部分按总席位计算，空席算零。百科泛称其提高国家运转效率，本地 `current_political_influence_impact` 可直接看到的具体效果是随影响力缩放阶层满意度恢复；不能由此推成生产、科研等全面加速。具体上限、基础速度、每项行动价格、储备带来的修正需要查定义与 tooltip，不能只凭这段说明编公式。（原版；TT119）

TT119 说明 1.4 政治外交调整，包括把某些原本主要靠金钱的政治行动转向影响力、强化阶层私军与政治取舍。涉及这类成本的旧攻略必须重读。不要把政治影响力当 EU4 的行政、外交、军事三类点数，也不要推断所有国内行动都消耗它。

### 7.4 议会是带条件的政策工具

议案可能为阶段目标创造机会，例如支持战争、发展或法律变化；为了取得支持可能要让步，且议会召开与议案结果受实际规则限制。Z15 显示想用议会解决小国扩张借口也会被局势、附庸身份和外交距离阻挡，不能把某议案写成所有国家随时可调用的按钮。

Z14 已完成全片转写审阅与画面核验：01:30—03:23 明确区分“用议会支持改法”与“保留支持通过议案取得长期修正”。选择要看初始支持、辩论中收益、通过后收益和失败代价；不是同一份支持可同时换全部奖励。作者的 1.2 评级按局面保留，不制成未经核验的 57 条现行数值表。（[议会视频案例](gameplay/Video_Ottomans_Economy_Parliament.md)）

官方教程 Z11/E09 13:52—16:25 还提供具体例子：匈牙利想建大教堂，初始议题支持不足，选择适合无海军国家的陆军议程并承担阶层／海军传统代价。片中只预期辩论结束后启动建设，未展示大教堂完工，任务验收应分开“议案通过”和“建筑竣工”。

## 8. 战争：动员、补给、交战、围城与停战

### 8.1 三种军事来源解决不同问题

| 来源 | 典型用途 | 玩家代价与限制 |
|---|---|---|
| 征召兵／Levies | 早期战争主体、临时扩大军力 | 人口离开生产岗位，死亡损失真实人口；解散和再次征召受规则限制 |
| 常备军／Regulars | 预先部署、训练、稳定战斗力、截击与关键战役 | 持续维护、人力补充、兵种解锁与补给成本 |
| 雇佣军／Mercenaries | 短期应急或补足专业兵力 | 现金和合约条件；1.3 有调整，不能套用旧版解雇与支付经验 |

早期常备军少不代表没有用途。Z03 作者利用可预先部署、集中和选择交战时机的优势对付分散敌军，但同时强调成本、兵种、平原和战斗规模条件。不能把个例改写成“前期全常备军必胜”。（Recap 6；TT104、113；Z03）

### 8.2 开战前先把战争写成可执行的路线

1. 解释战争目的和可强制的和平条款：夺地、臣服、联统、削弱敌人或解除威胁。
2. 检查借口、停战、稳定代价、敌方盟友、宗主与国际组织响应。
3. 确认军队如何到达目标：通行、海运、登陆点、海峡和封锁。
4. 标出能提供粮食和补给的友好地点、前进基地与关键要塞。
5. 规划集中交战、分兵围城、增援和撤退；预算战事超出预期时的开支。
6. 预设可以接受的停战结果，避免为边际收益打到财政与人口崩溃。

这是综合操作框架，不是保证胜利的算法。E03 英格兰与 E06 莫斯科的不同路线说明：相同的“军事强”可能对应快速决战，也可能对应避开优势敌军、占地与有限目标。

### 8.3 补给不是只看兵力上限

部队携粮与补给线路决定深入敌境的持续时间。辅助部队可提供支援功能；粮食短缺、距离、地形、气候、围城和敌方截断会改变损耗。1.2 日志进一步调整食物、补给和围城，具体数值必须读当前定义。（原版；Recap 6；TT104）

应分开看三种粮食压力：本国居民吃粮、驻军与部队消耗、远征军沿路获取补给。国家总粮食盈余不能证明某支深入敌国的军队能吃到粮。靠海战争还需要舰队与港口支持；抢到一个前进基地，可能比多赢一场无战略价值的战斗重要。

### 8.4 战斗为什么不能只比总人数

兵种、科技、士气、训练、将领、战线配置、地形、先后投入和增援共同决定战斗。官方介绍有中央、两翼与后备的结构；一翼崩溃可能连锁影响其他阵线。不同单位的入场速度与角色不同，且编制规模会随时代变化。（Recap 6）

因此不能给所有时代固定“步骑炮比例”，也不能把“20 个团”永远换算成同样人数。向 AI 请求战斗建议时，至少应提供时间／时代、双方实际人数和兵种、将领、士气、地形、粮食、援军及战争目的。Z03 的兵种数值只保留为当时作者条件下的经验。

### 8.5 围城与海军决定能不能兑现胜利

赢战斗未必能迫使敌人接受所需条约；必须占领相关目标、处理要塞和继续补给。围城会耗时并可能造成疾病、损耗、地方荒废。海军影响封锁、渡海、贸易和海上治理，海外战事要把舰队维护、水手、补给与登陆保护计入预算。（原版；Recap 6—7）

打完战争后检查：领土收益、现金、战损人口、债务、敌对感、边疆控制、整合队列和外交环境。若只有地图变色而财政及安全更差，不能仅以“胜利”评价该路线。

视频 Z10 的反例尤其具体：统一战争后新地购粮与治理建筑维护压低财政；01:12:38—01:14:38 作者取消江南征召以保生产，冬季仍加重缺粮；01:46:20—01:48:20 远征草原忽视前方补给，抵达伏尔加前已严重减员。兵力优势不能替代核心劳动力、季节与补给规划。（[大明阶段战报](gameplay/Video_Ming_Campaign.md)）

## 9. 外交：用关系改变战争与统治成本

### 9.1 结盟、人情与间谍网各有用途

盟友的数量不等于可用军力，要看对方态度、实际参战条件、是否能到战场，以及自己是否承担对方战争。人情可帮助组织合作，但其积累与使用有条件；Z01、E08 的外交案例体现了帮助盟友和未来扩张安排之间的联系。

外交官是可储存／增长并为行动消耗的资源，持续改善关系、人情和间谍网有按月成本；外交容量则衡量关系负担，强大盟友或大属国的负担可能更高。好感、信任和外交声誉也不是同一个值。不要把“还有一个外交官”或“还能加一个盟友”按 EU4 方式解释；具体消耗以当前互动为准。（Recap 7；本地证据）

间谍与制造借口服务于具体目标；有网不代表所有战争借口都自动可用。准备扩张时应查借口能要求什么、敌对感传播、停战和国际组织限制，避免赢了也拿不到预期收益。（原版；Recap 7；Z04 为旧版案例）

### 9.2 联统与属国是不同的扩张路线

王朝、婚姻、继承、联统领导权及整合可能以较少直接战争扩大统治，也可能导致继承争端或拖累外交容量。外交路线不是坐等随机继承：需要选择关系、管理忠诚、安排整合并为失败准备替代路线。（E01、E06—E08；Z01）

共主邦联是 Union 国际组织，成员通过相关法律和投票决定合作、长支领导及统一方向，不能当作普通附庸类型处理。婚姻连接具体王朝人物，继承契约、订婚和战争领导权又在 1.4 有调整，旧国家路线需要重审。（Recap 7；TT119）

属国类型并非完全等价。臣服方式、宗主权、可参与战争、外交自主、贡赋／人力、整合条件和文化适应需要分别检查。把新征服地区交属国可能缓解行政压力，却增加长期关系和忠诚问题。

### 9.3 敌对感、包围网与扩张节奏

原版 Antagonism 包含国家间基础差异，也包括某些行动在相关地点激起、随时间消退的敌对影响；附近国家根据利益相关程度反应。不能仅用“地图距离相同”或一个全世界统一数字推断谁会敌视自己。（原版）

对玩家而言，停战期可以用来改善关系、治理新地、回补财政和军力，再选下一个方向。Z01 的包围网挫折与 E08 的神罗扩张提醒：强军也不能忽视外交后果。设计征服任务时，应给停战恢复留空间。

### 9.4 国际组织提供另一层规则

神罗、教廷及其他组织有成员、领导权、法律或共同机制；加入、当选、改革和对成员动武的结果不同。皇帝不是一个全国属性加成，组织管理也不是普通附庸关系。E07—E08 与 Z01 的皇帝路线可作为具体案例，TT106 记录 1.2 的组织调整。（原版；Recap 7；TT106）

Towards Victory 自建贸易联盟等 IO 的脚本约束见项目 risk cards；那是本 mod 的实现选择，不应倒推为原版所有组织的玩法规则。

## 10. 人口、文化、宗教与社会价值

人口既提供生产和兵员，也有消费和政治态度。死亡、迁移和社会流动改变的不只是一个总人口数字，而是某地能否雇到特定工种、能否填满军队和谁获得财富。大规模奖励人口或改变人口类型会同时影响多个系统。（原版；Recap 1、5—6）

文化同化、接受文化、宗教转化与行政整合应分别设计。一个省已整合，不代表所有人口接受统治或宗教一致；获得文化接受也不等于瞬间同化。文化与语言还有文化力量、宫廷／礼仪语言和研究等联系，不只是消除叛乱的开关。（原版；Recap 5）

宗教可影响外交、阶层、研究、宗教行动和国际组织。有些国家目标应与宗教局势及制度分支相关。Z01 的胡斯成就路线适合学习“为未来宗教节点提前安排资源与关系”，不适合作为任何版本都固定在某年发生的脚本承诺。

艺术也有实际玩法功能。艺术家、委托作品、文化投资和作品持有影响文化力量、声望或传统；作品有质量、创作地点与移动限制，战争中可能遭掠夺或毁坏。文化胜利不能只用招到几个历史名人代替作品和社会基础；转移作品也不是所有艺术类型都适用。（Recap 5）

社会价值有方向选择和取舍，例如土地／海洋、集权／分权或其他当前可用轴。向某方向移动并非所有国家都更强；要根据领土形态、属国策略、军队和贸易定位选择。E06 的莫斯科案例中特别讨论集权与属国忠诚矛盾；具体修正应重新核对。

迁移可以帮助填补就业，不能保证政策下达后立刻获得足够工人。TT119 的强制迁移与 TT121 的远征均属新版相关内容，执行条件、成本、目的地和风险以当前实装为准。设计任务时不要把“迁移吸引力提高”直接等同“已经迁入 X 人”。

## 11. 科研、制度和时代：为下一阶段准备能力

原版说明每个时代有三项制度，先在适合地点出现，再传播；国家接纳相关制度后解锁许多进步。同一时间研究一项进步，速度与人口平均识字率、礼仪语言力量、教士阶层满意度及已接纳制度等因素有关。（原版）

这产生三类不同投资：

1. **知识条件**：推动制度传播或使用研究制度的内阁行动，争取能研究。
2. **研究能力**：改善识字率、相关人物与阶层条件，争取更快研究。
3. **研究选择**：选择能解决现实瓶颈的进步，争取研究有用。

例如准备发展常备军，先检查制度与兵源建筑解锁，再安排兵员、财政和军队；准备远洋贸易，则要同时检查贸易距离、探索及船舶条件。完成科技前置不自动解决缺粮、缺人和缺钱。

**不要硬编码旧时代年份。** 本地时代文件甚至与常见旧版文艺复兴年份不同；详细 key 与现值见[本地原版证据](gameplay/Vanilla_Evidence.md)。脚本应优先用时代／制度状态和实际解锁条件，除非任务本来就需要一个经核对的历史日期。

科研胜利路径应兼顾研究完成、制度接纳、教育基础与真正采用成果。只数已研究科技可能偏向国家独有树或已有强开局；只数大学又可能奖励空建筑。Eureka 等科研机制应描述“怎样改变选择”，例如给特定产业路线的研究提供条件性推动，而不是默认免费补全全部知识体系。

Z10 结尾示范为制度远征：取得意大利附属后请求知识分享，提高传播速度。实际已观察的是“建立渠道并开始传播”，约七年后取得三制度只是作者预计；影片没有展示接纳完成。科学／征服复合任务可拆成渠道、传播、接纳、研究四阶段，不能把第一步算成最后一步。（[视频 01:52:50—01:54:22](gameplay/Video_Ming_Campaign.md)）

## 12. 探索、殖民与 1.4 远征

探索处理未知地区的信息，殖民处理实际占据与治理，贸易处理跨市场流动，三者不是同一项进度。玩家需要探索／殖民能力、可达距离、资金、人口、船舶和补给，还要考虑殖民地与宗主之间的关系。（原版；Recap 4、7）

海外布局应先解释收益路径：新资源是否有销路？能否运回核心市场？前进基地是否缩短航程？能否治理或建立适当属国？为追求某资源付出的舰队与战争成本是否合理？Z02 的殖民跳板与 E01 的殖民国管理提供了具体取舍，不能直接泛化成所有国家最佳路线。

殖民地越多不必然越好。E01 讨论殖民国规模与关系负担；E13 的作者抱怨大量探索与殖民事件反复管理。对任务和奇观而言，应关注网络是否真正运作，而不是单纯鼓励一百个长期微管理对象。

TT121 的远征是 1.4 预览的新功能框架，不应与传统探索直接画等号。远征有目的、人员和预算选择及风险回报；TT127 又涉及 DLC 机械内容。具体远征类型哪些免费、哪些需要 DLC，以及完成结果如何落地，须读[官方更新](gameplay/Official_Updates.md)并查当前内容。

## 13. 国别与环境怎样改变策略

以下只比较局面与推理，操作细节、结果和版本条件见[完整案例](gameplay/Player_Cases.md)。

| 局面／案例 | 核心问题 | 有代表性的取舍 |
|---|---|---|
| 波西米亚胡斯目标（Z01） | 宗教目标、皇位与邻国关系交织 | 提前组织外交，承受瘟疫和包围网后调整节奏 |
| 欧洲贸易小国（Z02） | 人口与国土小，靠大市场放大收入 | 外国贸易据点／市场关系有收益，也依赖市场存续 |
| 早期常备军（Z03） | 维护贵但可提前集中 | 为关键截击购买战斗主动权，不能无视地形规模 |
| 拜占庭危机（Z04） | 灾难与强邻迫使先求生存 | 先解除当前限制再反击；涉及当时 bug 的步骤不复用 |
| 大明经营（Z05—Z06） | 规模大但行政与人口结构限制收益 | 沿海连接与产业布局优先于无条件扩大疆域 |
| 卡斯蒂利亚（E01） | 内政、伊比利亚扩张、联统和海外同时竞争资源 | 先确定阶段重点，再转向海洋路线；不是全线同时做 |
| 奥斯曼（E02） | 连续扩张下如何消化安纳托利亚与巴尔干 | 核心区投资、属国与直辖、文化宗教整合的平衡 |
| 英格兰（E03） | 大陆战争与海岛安全、长期海外潜力 | 承担大陆投入，或减少大陆负担以集中其他路线 |
| 莫斯科（E06） | 内部联统／附庸结构、草原强敌 | 保守整合或激进战争；防御避强、占地与外交组合 |
| 奥地利（E07） | 军事强、财政弱、山地治理与市场接入 | 行政与产业组织可能比继续扩军更急迫 |
| 勃兰登堡（E08） | 低控制边疆、神罗内扩张与未来目标 | 属国管理、借盟友积人情、控制敌对感、选择帝国路线 |
| 理塘失败战报（Z15） | 附庸身份、外交距离、小国能力约束 | 有资源也未必有合法行动；带 mod 且未完结，只学约束识别 |

目前来源对欧洲明显更丰富。对中国以外的非欧洲国家，不能从欧洲阶层、神罗与联统路线直接外推；应补读该国实际政府、宗教、市场与特殊局势。Z06 的国家强弱排行只是作者早期经验。

## 15. 后续 AI 的查证规则与常见误用

1. **先说明当前局面，再给动作。** 不在不知道国家、时代和市场的情况下给确定开局。
2. **先找实际瓶颈，再给修正。** 缺工、缺投入、低控制、低可及性是不同问题。
3. **分清数据层。** 资源潜力、建成等级、实际就业、生产效率、产量、利润、税基和税收不得互换。
4. **分清政治与文化状态。** 征服、整合、核心、接受文化、同化和转教分别核对。
5. **分清钱与资源。** 有钱不保证有建材、船员、工人、政治影响力或可用内阁席位。
6. **不照搬 EU4。** 不假设固定贸易流、点数造核、固定团人数或固定步骑炮比例。
7. **不复制旧 bug 路线。** Z04 灾难顺序、旧版特殊吞并或降维护技巧须重新验证。
8. **不把开发日志当现行实测。** 1.4 预览、DLC 内容与本地可用功能分层记录。
9. **不凭页面更新时间定版。** Wiki 新修订可能仍有 pre-release／rewrite 标记。
10. **不凭视频标题生成操作。** 未观看或无可审阅字幕的资料保持待研究状态。
11. **不把文件存在当引擎行为已证实。** tooltip、定义、脚本效果与实际结算可能不同；重要数值需运行验证。
12. **保留证据链。** 新结论写明来源、版本、条件；若与本文冲突，更新主文与阅读记录，勿不断叠加相互矛盾的建议。
