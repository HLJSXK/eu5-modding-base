# Events: shared EU5 checks

Verify event IDs, namespace, supported fields, localization keys, and option effects against current vanilla or official definitions. Event option tooltips may pre-evaluate visible and hidden effect chains; a successful click path alone does not prove the hover path safe. Preserve dynamic engine-generated descriptions when a preview fails, and verify scope links and parser output before adding text-only substitutes.

Use the workspace event tests and runtime logs for confirmation. Workspace cards add project-specific event protocols.
