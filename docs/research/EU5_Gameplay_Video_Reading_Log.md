## 2. 获取和转写方法

1. 使用 B 站公开元数据、播放器和播放流接口。8 条均取得完整音轨与 360p 视频；五条短视频又取得 480p 版本供重点核对。未使用账户 cookies。
2. 公开独立字幕列表均为空；这只说明没有取得单独字幕文件，视频本身包含烧录字幕。
3. 本地 `faster-whisper 1.2.1`、`CTranslate2 4.8.3`，采用 `faster-whisper-large-v3-turbo`、中文、CUDA `int8_float16`、beam size 3、batch size 16 和 VAD。Z11 音轨实际是中文配音，初次误设英文的输出已废弃，知识采用重跑的中文稿。
4. 模型来自 ModelScope 公开仓库 `pengzhendong/faster-whisper-large-v3-turbo`；逐文件大小／SHA-256 与仓库公开记录匹配。来源 revision、URL、模型卡许可及哈希见快照；哈希证明内容身份，不证明转写正确。
5. 初稿以约半分钟片段输出，审阅时结合全片分布的画面，再对重要数字、名词、动作与结果按时间精确抽帧。
6. 对 Z07a、Z09、Z10、Z11 可疑时段及 Z12 一处错误重新解码转写，仍保留机器性质，不自动覆盖原稿或把补稿当事实。

可复用的[本地转写脚本](../../scripts/research/transcribe_gameplay_videos.py)只处理明确给定的本地音轨与模型，不自动下载或上传内容。媒体、模型、依赖和逐字稿是研究缓存，不纳入知识正文；持久化交付保存原创总结、时间戳和来源快照。

## 6. 复查与维护

快照保存每条音视频的 SHA-256、BVID/CID、时长、模型参数、转写摘要哈希、核验画面时间点及未读条目。网页或媒体更新后重新取得文件应比对这些值。新增字幕或高清画面只升级实际核验过的段落，不把整条视频自动标为逐秒校对完成。

本轮保留研究工具供复用；下载媒体、模型和依赖不进入版本库。后续即使移除缓存，笔记、来源链接、时间戳与快照仍可独立查阅。
