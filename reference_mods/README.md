# Community mod reference snapshots

This directory preserves the complete source snapshot previously used by `eu5-modding-project`. The independent `eu5-towards-victory` snapshot is preserved at [`reference_mods_variants/eu5-towards-victory`](../reference_mods_variants/eu5-towards-victory/). Both variants are intentional: five Workshop IDs contain same-path, different-content files, and each source also has unique files. Scripts in each workspace read its own recorded variant so extraction does not change generated output. See [`migration/source_manifest.json`](../migration/source_manifest.json).

Mod `3698931463` is an old published SOL snapshot, not independent third-party evidence. The index and metadata inside each snapshot may describe older game versions; verify current syntax against official definitions and game files first.
